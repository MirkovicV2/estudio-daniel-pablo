# Identidad propuesta — Puntal

## Estado

**Nombre de trabajo:** Puntal · Estudio digital  
**Estado:** propuesta para Daniel y Pablo. Pendiente de su aprobación y de revisar marca, dominio y perfiles antes de cualquier uso público.

La web local incorpora esta propuesta para que se pueda valorar en contexto. No representa un cambio legal de denominación, una empresa registrada ni una marca disponible.

## Núcleo

**Qué hacemos:** combinamos diseño visual y desarrollo para mejorar cómo un negocio se presenta y cómo funcionan sus herramientas digitales.

**Para quién:** negocios y profesionales que necesitan una presencia digital más clara, una web, contenido o conexiones entre herramientas. La web no atribuye clientes, resultados ni servicios operativos que no estén verificados.

**Idea central:** ser un apoyo firme para ordenar y construir el siguiente paso digital de un negocio. “Puntal” da una imagen concreta de soporte; funciona junto a las dos especialidades que ya constan en el estudio.

**Promesa verbal:** Diseño claro. Tecnología bien conectada.

**Descriptor:** Estudio digital.

## Voz

- Directa, cercana y concreta; hablar de necesidades y entregables.
- Explicar automatización y asistentes como temas sujetos a viabilidad.
- Evitar superlativos, jerga vacía y promesas de crecimiento o ahorro.
- Mantener visibles los papeles de Daniel (desarrollo) y Pablo (diseño).

## Sistema visual

| Elemento              | Uso                                                |
| --------------------- | -------------------------------------------------- |
| Carbón `#25271F`      | Texto, trazo principal y contraste                 |
| Papel `#F7F3EA`       | Fondo principal                                    |
| Teja `#BD4D32`        | Acento, enlaces y punto de unión                   |
| Melocotón `#F1D2C4`   | Superficies gráficas secundarias                   |
| Gris piedra `#64665D` | Texto secundario; comprobar contraste por contexto |
| Space Grotesk         | Titulares y marca                                  |
| DM Sans               | Lectura y navegación                               |

El símbolo original combina la letra P con dos apoyos y una unión horizontal. El logotipo se compone de símbolo y nombre; el isotipo funciona solo en favicon y tamaños reducidos. No usar el naranja como texto pequeño sobre fondos claros: reservarlo para elementos grandes, gráficos y acentos; los enlaces usan el tono teja oscuro definido en CSS.
